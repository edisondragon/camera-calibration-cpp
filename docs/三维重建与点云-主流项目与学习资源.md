# 第 2 章　路线 A：双目立体视觉

这是**投入产出比最高**的一条路。标定好两个相机，就能算出深度。

## 2.1 核心概念

```
   左相机标定 K1, dist1
   右相机标定 K2, dist2
   两者之间的相对位姿 R, t        <-- 双目标定
        │
        v
   立体校正 (stereoRectify)
   把两张图"摆正"，使对应点在同一水平线上
        │
        v
   立体匹配 (StereoBM / StereoSGBM)
   对左图每个像素，在右图同一行找最匹配的像素
        │
        v
   视差图 (disparity)
        │
        v
   深度 = 焦距 * 基线 / 视差        <-- 就是这个简单公式
        │
        v
   点云
```

**深度公式**：

```
   Z  =  f * B / d
```

- f：焦距（像素）
- B：两相机基线距离
- d：视差（左右图中同一个点的横向像素差）

**关键**：视差 d 出现在分母，所以**视差小的地方深度误差极大**。
远处物体测不准，这是原理性的限制，不是算法问题。

## 2.2 OpenCV 的双目模块

- 文档：https://docs.opencv.org/4.x/dd/d53/tutorial_py_depthmap.html
- `cv::stereoCalibrate`：双目标定
- `cv::stereoRectify`：立体校正
- `cv::StereoBM` / `cv::StereoSGBM`：立体匹配
- `cv::reprojectImageTo3D`：视差转三维点
- 语言：C++ / Python
- 难度：中

## 2.3 disp OpenCV 的 community 模块（更好的立体匹配）

- 仓库：https://github.com/opencv/opencv_contrib （`opencv_contrib/modules/stereo`）
- **说明**：里面有 `QuasiDenseStereo`、`stereo_match` 等更好的算法。

## 2.4 专题仓库

- GitHub topic：https://github.com/topics/stereo-calibration
- 里面有很多双目标定 + 三维追踪的小项目，
  比如把便宜的 USB 双目摄像头变成 XYZ 追踪器，适合入门。

## 2.5 进阶：自己写立体匹配

如果你想理解立体匹配的本质（而不是调库），推荐从**半全局匹配（SGM）**入手：

- 原始论文：Hirschmüller, "Stereo Processing by Semiglobal Matching
  and Mutual Information", TPAMI 2008
- **为什么推荐 SGM**：它是"动态规划 + 多方向聚合"，算法逻辑清晰，
  几百行就能实现一版。而且 OpenCV 的 `StereoSGBM` 就是它。

# 第 3 章　路线 B：运动恢复结构（SfM）

**这是三维重建的学术主线。** 输入一堆照片，输出相机位姿 + 稀疏三维点。

## 3.1 流程

```
   1. 特征提取           SIFT / SURF / AKAZE
        │
   2. 特征匹配           暴力匹配 + Lowe 比率检验
        │
   3. 几何验证           对极几何 RANSAC 剔除外点
        │
   4. 初始重建           选两张基线合适的图，E 矩阵分解 + 三角化
        │
   5. 增量式建图         不断加入新视角，PnP 求位姿，三角化新点
        │
   6. 束调整 (Bundle Adjustment)    全局优化所有位姿和点
        │
        v
   稀疏点云 + 每张图的位姿
```

**注意**：标定在这里的角色是——你可以先用棋盘格标定出内参，
然后 SfM 就只用求外参（叫"已知内参的 SfM"，稳定得多）。
也可以让 SfM 顺便自标定内参（叫"未知内参"，更脆弱）。

## 3.2 COLMAP —— 事实标准

- 仓库：https://github.com/colmap/colmap
- 网站：https://colmap.github.io/
- 语言：C++（核心）+ Python 绑定（pycolmap）
- 难度：中（用）/ 高（读源码）
- **特点**：
  - SfM + MVS 全套，**开源三维重建里质量最好、用得最广**
  - 有 GUI，也有命令行
  - 支持已知内参、已知位姿、自定义畸变模型
  - 代码质量高，是学习 SfM 工程实现的最好材料
  - `pycolmap` 可以在 Python 里直接调

**上手命令**：

```bash
# 全自动重建（一条命令）
colmap automatic_reconstructor \
    --workspace_path ./workspace \
    --image_path ./images
```

**读源码的建议顺序**：

```
   src/colmap/sfm/            增量式重建主流程
   src/colmap/estimators/     各种估计器（本质矩阵、单应、PnP）
   src/colmap/optim/          优化（包含 LM、RANSAC）
   src/colmap/mvs/            稠密重建
```

## 3.3 OpenMVG —— 更适合学习

- 仓库：https://github.com/openMVG/openMVG
- 网站：http://openmvg.readthedocs.io/
- 语言：C++（头文件为主）
- 难度：中
- **特点**：
  - **只做 SfM，不做 MVS**，职责单一，代码更好读
  - 大量模板化设计，接口干净
  - 社区讨论：https://github.com/openMVG/openMVG/discussions/2165
    （十周年回顾，里面聊了它现在的定位）

**和 COLMAP 的选择**：

| | COLMAP | OpenMVG |
|---|---|---|
| 重建质量 | 更好 | 好 |
| MVS | 内置 | 需要配 OpenMVS |
| 代码可读性 | 中 | 更好 |
| 学习推荐 | 跑结果 | **读代码** |

## 3.4 TheiaSfM

- 仓库：https://github.com/sweeneychris/TheiaSfM
- 语言：C++
- 难度：中
- **特点**：由 Chris Sweeney 开发，设计上强调**模块化和可插拔**，
  可以在不改核心代码的情况下换掉任何一步。学术研究友好。

## 3.5 综述论文（先读这个，别急着看代码）

- **Stathopoulou et al., "Open-Source Image-Based 3D Reconstruction:
  Review, Comparison and Evaluation", ISPRS 2019**
- PDF：https://isprs-archives.copernicus.org/articles/XLII-2-W17/331/2019/isprs-archives-XLII-2-W17-331-2019.pdf

  用了多个数据集，给了精度/耗时/鲁棒性的定量对比。
- **为什么推荐**：读完你就有"该选哪个"的判断力了，不用自己瞎试。

# 第 4 章　多视图立体（MVS）：稀疏 → 稠密

SfM 出来的是**稀疏点云**（几百到几万个点，只有特征点）。
要得到**稠密点云**（每个像素一个点），需要 MVS。

## 4.1 OpenMVS

- 仓库：https://github.com/cdcseacave/openMVS
- 语言：C++
- 难度：中到高
- **特点**：
  - 稠密点云、网格重建、网格精化、纹理映射，全套
  - 常和 OpenMVG 搭配使用（OpenMVG 出位姿，OpenMVS 做稠密）
  - 输入是 COLMAP / OpenMVG 的格式，衔接方便
- **典型流程**：

```
   DensifyPointCloud   ->  稠密点云 (.ply)
   ReconstructMesh     ->  网格
   RefineMesh          ->  网格精化
   TextureMesh         ->  纹理
```

## 4.2 MVE（Multi-View Environment）

- 仓库：https://github.com/simonfuhrmann/mve
- 语言：C++
- 难度：中
- **特点**：由 Simon Fuhrmann 开发，配套有 `mve`（重建）和 `UMVE`（可视化）。
  文档写得好，流程清晰。

## 4.3 其他

- **SMVS**（Shading-aware Multi View Stereo）
  仓库：https://github.com/flanggut/smvs
  特点：利用了光度一致性，对弱纹理表面效果更好

- **MVSNet 及后续（学习方法）**
  特点：用深度学习做 MVS，代表性工作有 MVSNet、R-MVSNet、CasMVSNet、
  PatchmatchNet。这条线已经和传统方法分道扬镳，属于深度学习范畴。

# 第 6 章　点云处理库

拿到点云之后，要做的事：滤波、配准、分割、重建网格、可视化。

## 6.1 Open3D —— 现在的首选

- 仓库：https://github.com/isl-org/Open3D
- 网站：http://www.open3d.org/
- 语言：C++（核心）+ Python（重点维护）
- 难度：低
- **特点**：
  - Intel 出品，**API 现代、简洁、文档好**
  - Python 是主力接口，学习成本极低
  - 功能覆盖：读写、滤波、配准（ICP）、表面重建（Poisson）、可视化
  - 内置了和 COLMAP 流程的对接

**入门示例**：

```python
import open3d as o3d

pcd = o3d.io.read_point_cloud("cloud.ply")
print(pcd)                                  # 看点数、范围

# 下采样
down = pcd.voxel_down_sample(voxel_size=0.005)

# 法线估计（做表面重建必需）
down.estimate_normals(
    o3d.geometry.KDTreeSearchParamHybrid(radius=0.02, max_nn=30))

# 离群点去除
clean, _ = down.remove_statistical_outlier(nb_neighbors=20, std_ratio=2.0)

# 泊松表面重建
mesh, _ = o3d.geometry.TriangleMesh.create_from_point_cloud_poisson(
    clean, depth=9)

o3d.visualization.draw_geometries([clean, mesh])
```

# 第 7 章　优化后端（束调整的引擎）

SfM 的核心是**束调整（Bundle Adjustment）**——一个超大规模的非线性最小二乘。

它的形式和你学过的 LM 精化**完全一样**：

```
   最小化  Σ  Σ  ‖ 观测 - 投影(内参, 外参, 三维点) ‖²
```

只不过未知数从"5 个内参 + 6n 个外参"变成了
"5 个内参 + 6n 个外参 + 3m 个三维点"，m 可能有几十万。

直接解不动，所以用**稀疏性 + Schur 补**。这就是为什么需要专门的求解器。

## 7.1 Ceres Solver —— 最推荐

- 仓库：https://github.com/ceres-solver/ceres-solver
- 网站：http://ceres-solver.org/
- 语言：C++
- 难度：中
- **特点**：
  - Google 出品，**非线性最小二乘的事实标准**
  - 自带自动微分——你只要写残差函数，不用手推雅可比
  - COLMAP 用的就是 Ceres
  - 有完整的 BA 教程：http://ceres-solver.org/nnls_tutorial.html

**为什么对你很重要**：你现在手推了 LM 的雅可比，
用 Ceres 时就能理解"自动微分到底在替你做什么"，而不是当黑盒用。

## 7.2 g2o

- 仓库：https://github.com/RainerKuemmerle/g2o
- 语言：C++
- 难度：中
- **特点**：图优化框架，SLAM 领域常用。

## 7.3 GTSAM

- 仓库：https://github.com/borglab/gtsam
- 语言：C++ / Python
- 难度：中到高
- **特点**：因子图和增量式优化，SLAM 和 SfM 都用。

## 7.4 从 LM 到 BA 的思路

你现在的 LM 解的是 `(J^T J + μD) δ = -J^T r`，

未知数顺序是 `[内参, 外参1, 外参2, ..., 外参n]`。

BA 里多了三维点，未知数变成 `[内参, 外参1..n, 点1..m]`。

关键观察：**每个三维点只被少数几张图看到**，所以 `J^T J` 是**稀疏**的，
结构是：

```
        ┌                          ┐
        │  U     W1   W2  ...  Wn   │      U  = 相机参数块（稠密但小）
        │  W1^T  V1    0   ...   0  │      Vi = 第 i 个点的参数块（3x3）
        │  W2^T   0   V2   ...   0  │      Wi = 耦合块
        │  ...                    │
        │  Wn^T   0    0   ...  Vn  │
        └                          ┘
```

因为每个 `Vi` 是 3×3 且独立，可以**先消掉所有点**（Schur 补），
只对相机参数求解，然后再回代求点。

```
   ( U - Σ Wi Vi^(-1) Wi^T )  δ_cam  =  ...
```

这就是 BA 的核心技巧，也是 COLMAP 这类软件能处理几十万点的原因。

# 第 10 章　建议的动手顺序

按这个顺序做，每一步都能跑出可见的结果，不会卡住。

## 阶段一：把标定吃透（1~2 周）

1. 编译运行本项目的 `cpp-zhang-calib`，看懂输出
2. 运行 `tools/zhang_reference.py`，对比 C++ 和 Python 的结果
3. 用 OpenCV 版标定一个真实的棋盘格（打印一张，拍照）
4. 对比你的结果和 MATLAB / OpenCV 的结果，差多少？为什么？

**验收标准**：重投影误差 < 0.5 像素，你能解释每一个参数的含义。

## 阶段二：双目标定 + 深度（2~3 周）

1. 用 OpenCV 的 `stereoCalibrate` 标定一组双目图像
2. 用 `stereoRectify` 校正，检查校正后的图对极线是否水平
3. 用 `StereoSGBM` 算视差图
4. 用 `reprojectImageTo3D` 得到点云，用 Open3D 显示
5. 改基线、改距离，观察点云质量如何变化

**验收标准**：能看到清晰的点云，能理解"为什么远处测不准"。

## 阶段三：跑通一次完整 SfM（1 周）

1. 下载 Meshroom，拖一批照片进去，跑通
2. 看它的节点图，理解每一步在干什么
3. 换 COLMAP 命令行再跑一遍，对比结果
4. 用 CloudCompare 对比两个结果的点云差异

**验收标准**：能独立完成一次端到端重建，知道每一步的输入输出。

## 阶段四：读 SfM 源码（4~8 周）

1. 用 OpenMVG，因为它的代码更好读
2. 从特征提取开始，一路读到束调整
3. 重点看 `estimators` 目录：本质矩阵怎么估的、PnP 怎么解的、RANSAC 怎么组织的
4. 对照 Ceres 的文档，理解 BA 是怎么调用优化器的

**验收标准**：能说清"给定一批照片，从像素到三维点，数据经过了哪些变换"。

## 阶段五：自己实现一个最小 SfM（长期）

只做两视图到三视图：

```
   两张图 -> SIFT 匹配 -> 本质矩阵 RANSAC -> 分解得 R,t
          -> 三角化得三维点 -> 第三张图 PnP 加进来
          -> 用 Ceres 做一次小规模 BA
```

**这一步做完，你就真正理解三维重建了。**

## C. 从标定到点云的最小代码路径

```python
import cv2, numpy as np, open3d as o3d

# 1. 标定（用你已经会的）
K = np.array([[1200, 0, 640], [0, 1150, 480], [0, 0, 1]], float)
dist = np.zeros(5)

# 2. 读双目图
left  = cv2.imread("left.png",  0)
right = cv2.imread("right.png", 0)

# 3. 立体匹配
matcher = cv2.StereoSGBM_create(minDisparity=0, numDisparities=128,
                                blockSize=5)
disp = matcher.compute(left, right).astype(np.float32) / 16.0

# 4. 视差 -> 三维点
#    基线 B = 120mm，焦距用 K[0,0]
f = K[0, 0]
B = 120.0
Q = np.float32([[1, 0, 0, -K[0, 2]],
                [0, 1, 0, -K[1, 2]],
                [0, 0, 0,  f],
                [0, 0, -1.0/B, 0]])
points = cv2.reprojectImageTo3D(disp, Q)

# 5. 转成 Open3D 点云
mask = disp > disp.min()
pcd = o3d.geometry.PointCloud()
pcd.points = o3d.utility.Vector3dVector(points[mask])
o3d.visualization.draw_geometries([pcd])
```
