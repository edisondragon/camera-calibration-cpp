# 第 0 章　符号约定

在开始之前统一记号，后面全部遵循。

| 符号 | 含义 | 维数 |
|---|---|---|
| M = (X, Y, Z) | 世界坐标（三维点） | 3 |
| Mh = (X, Y, Z, 1) | 世界坐标的齐次形式 | 4 |
| Xc = (Xc, Yc, Zc) | 相机坐标 | 3 |
| p = (u, v) | 像素坐标 | 2 |
| ph = (u, v, 1) | 像素坐标的齐次形式 | 3 |
| K | 内参矩阵 | 3×3 |
| R | 旋转矩阵（正交，行列式 = +1） | 3×3 |
| t | 平移向量 | 3×1 |
| r1, r2, r3 | R 的三个列向量 | 3×1 |
| H | 单应矩阵 | 3×3 |
| h1, h2, h3 | H 的三个列向量 | 3×1 |
| hij | H 第 i 行第 j 列的元素 | 标量 |
| B | 等于 K 的逆转置 乘 K 的逆 | 3×3 |
| Bij | B 第 i 行第 j 列的元素 | 标量 |
| b | B 的六个独立元素拉成的列向量 | 6×1 |
| V | 约束矩阵 | 2n×6 |
| s, λ, η, ξ | 各种尺度因子（不为零，数值无所谓） | 标量 |
| (xn, yn) | 归一化坐标（无畸变） | 2 |
| (xd, yd) | 归一化坐标（含畸变，即观测到的） | 2 |
| k1, k2 | 径向畸变系数 | 标量 |
| n | 拍摄的图像张数 | 整数 |
| m | 每张图的角点数 | 整数 |

**两个反复使用的记号约定**：

1. **相似号 ~**：A ~ B 表示"A 和 B 只差一个非零倍数"，即存在 s ≠ 0 使 A = s·B。
2. **上标 T**：转置。上标 -1：求逆。

**一个贯穿全文的符号 η**：因为 B 只能确定到相差一个尺度，
我们把"算法实际解出来的 B"记作 B，把"理论上的 B"记作 η · B。
（即 B = η · K 的逆转置 乘 K 的逆。）第 7 章会看到 η 自动被消掉。

# 第 1 章　相机模型

## 1.1 三步投影

从世界点到像素，经过三个变换：

```
   第一步（刚体变换，线性）

        Xc       [ R   t ]  [ M ]
        Yc   =   [       ]  [   ]
        Zc       [ 0   1 ]  [ 1 ]

   展开：Xc = R·M + t

   第二步（透视除法，非线性）

        xn  =  Xc / Zc

        yn  =  Yc / Zc

   第三步（仿射变换，线性）

        u   =  α·xn + γ·yn + u0

        v   =  β·yn + v0
```

## 1.2 内参矩阵

第三步写成矩阵形式：

```
        [ u ]     [ α   γ   u0 ] [ xn ]
        [ v ]  =  [ 0   β   v0 ] [ yn ]
        [ 1 ]     [ 0   0    1 ] [ 1  ]
```

所以内参矩阵是：

```
        [ α   γ   u0 ]
   K =  [ 0   β   v0 ]
        [ 0   0    1 ]
```

**K 是上三角矩阵**，这个性质在后面求逆和分解时反复用到。

五个参数的含义：

- α = f / dx，x 方向焦距（像素单位）
- β = f / dy，y 方向焦距
- γ，像素轴的倾斜因子（现代相机约等于 0）
- u0, v0，主点（光轴与像平面的交点）的像素坐标

## 1.3 完整合成公式

把三步串起来，用齐次坐标写成一条：

```
   s · (u, v, 1)  =  K · [ R | t ] · (X, Y, Z, 1)
```

或者完全展开：

```
   s · [ u ]     [ α   γ   u0 ] [ r11  r12  r13  t1 ] [ X ]
       [ v ]  =  [ 0   β   v0 ] [ r21  r22  r23  t2 ] [ Y ]
       [ 1 ]     [ 0   0    1 ] [ r31  r32  r33  t3 ] [ Z ]
                                                       [ 1 ]
```

其中 s 是任意非零尺度因子（见符号约定的相似号）。

**注意**：s 不是未知数，它只是让等式成立的占位符。

## 1.4 内参矩阵的逆（推导）

这是后面反复要用的工具，先推出来。

设

```
               [ a   b   c ]
   K^(-1)  =   [ 0   d   e ]
               [ 0   0   1 ]
```

（逆矩阵也是上三角，因为上三角矩阵的逆还是上三角。）

**利用 K · K^(-1) = I 逐项求解。**

先从第一个基向量出发，即 K · K^(-1) 的第一列应该等于 (1, 0, 0)：

```
   K 的第 1 行 乘 K^(-1) 的第 1 列：
        α·a + γ·0 + u0·0  =  α·a  =  1
   ==>  a  =  1 / α
```

```
   K 的第 2 行 乘 K^(-1) 的第 1 列：
        0·a + β·0 + v0·0  =  0          （自动满足）
   K 的第 3 行 乘 K^(-1) 的第 1 列：
        0·a + 0·0 + 1·0  =  0           （自动满足）
```

再看第二列应该等于 (0, 1, 0)：

```
   K 的第 1 行 乘 K^(-1) 的第 2 列：
        α·b + γ·d + u0·0  =  α·b + γ·d  =  0
   ==>  b  =  -γ·d / α  =  -γ / (α·β)

   K 的第 2 行 乘 K^(-1) 的第 2 列：
        0·b + β·d + v0·0  =  β·d  =  1
   ==>  d  =  1 / β
```

（注意 b 的推导要用到 d，所以先算 d 再算 b，顺序不能反。）

最后第三列应该等于 (0, 0, 1)：

```
   K 的第 2 行 乘 K^(-1) 的第 3 列：
        0·c + β·e + v0·1  =  β·e + v0  =  0
   ==>  e  =  -v0 / β

   K 的第 1 行 乘 K^(-1) 的第 3 列：
        α·c + γ·e + u0·1  =  0
   ==>  c  =  -(γ·e + u0) / α
             =  -(γ·(-v0/β) + u0) / α
             =  (γ·v0/β - u0) / α
             =  (γ·v0 - β·u0) / (α·β)
```

**汇总**：

```
   等于 1/α                  当 (i,j) = (1,1)

   等于 -γ/(α·β)             当 (i,j) = (1,2)

   等于 (γ·v0 - β·u0)/(α·β)  当 (i,j) = (1,3)

   等于 1/β                  当 (i,j) = (2,2)

   等于 -v0/β                当 (i,j) = (2,3)

   等于 1                    当 (i,j) = (3,3)
```

写成矩阵：

```
               [ 1/α   -γ/(αβ)   (γ·v0 - β·u0)/(αβ) ]
   K^(-1)  =   [  0      1/β           -v0/β         ]
               [  0       0               1          ]
```

**手算检查**：把 K 和 K^(-1) 乘起来，应该得到单位矩阵。
建议至少验证 (1,2) 和 (1,3) 两个位置。

# 第 2 章　平面单应矩阵

## 2.1 平面假设让 r3 消失

标定板是平面。我们**选择**世界坐标系使标定板躺在 Z = 0 平面上。

把 Z = 0 代入第 1.3 节的公式：

```
   s · (u, v, 1)  =  K · [ r1  r2  r3  t ] · (X, Y, 0, 1)
```

把矩阵乘向量展开：

```
   [ r1  r2  r3  t ] · (X, Y, 0, 1)

        =  X·r1 + Y·r2 + 0·r3 + 1·t

        =  X·r1 + Y·r2 + t
```

**关键**：r3 前面的系数是 Z = 0，所以 r3 整个消失了。

再把 X·r1 + Y·r2 + t 写成矩阵乘向量的形式：

```
   X·r1 + Y·r2 + t  =  [ r1  r2  t ] · (X, Y, 1)
```

（验证：把右边展开 = X·r1 + Y·r2 + 1·t。对上了。）

所以：

```
   s · (u, v, 1)  =  K · [ r1  r2  t ] · (X, Y, 1)
```

## 2.2 单应矩阵的定义

定义

```
   ★   H  =  K · [ r1  r2  t ]
```

H 是 3×3 矩阵。把它的三列记作 h1, h2, h3：

```
   H  =  [ h1  h2  h3 ]
```

**H 的列和 K, R, t 的关系**（这个恒等式后面反复用）：

```
   h1  ~  K · r1

   h2  ~  K · r2

   h3  ~  K · t
```

（因为 H = K·[r1 r2 t]，按列展开就是这三个式子，各自相差同一个尺度。）

## 2.3 单应矩阵的自由度计数

H 有 9 个元素。但因为 (u, v, 1) ~ H·(X, Y, 1) 这个关系是齐次的，
H 乘任何非零常数都不改变投影结果。

所以：

```
   9 个元素  -  1 个整体尺度  =  8 个自由度
```

这就是为什么需要 8 个方程，也就是 4 个点（每点 2 个方程）。

# 第 3 章　单应矩阵的线性求解（DLT）

## 3.1 用叉乘消去尺度因子

我们有：

```
   (u, v, 1)  ~  H · (X, Y, 1)
```

**不能直接写成等式**，因为尺度未知。用第 6 章（叉乘性质）的办法消掉它：

两个向量方向相同，则叉乘为零向量：

```
   ★   (u, v, 1)  ×  [ H · (X, Y, 1) ]  =  (0, 0, 0)
```

## 3.2 逐步展开叉乘

先算出 H·(X, Y, 1) 的三个分量。把 H 按行展开：

```
        [ h11  h12  h13 ]
   H =  [ h21  h22  h23 ]
        [ h31  h32  h33 ]
```

于是：

```
   H · (X, Y, 1)  =  ( h11·X + h12·Y + h13 ,
                       h21·X + h22·Y + h23 ,
                       h31·X + h32·Y + h33 )
```

为书写简洁，把这三个分量依次记作 A, B, C：

```
   A  =  h11·X + h12·Y + h13

   B  =  h21·X + h22·Y + h23

   C  =  h31·X + h32·Y + h33
```

现在算叉乘 (u, v, 1) × (A, B, C)。按叉乘公式：

```
   第一个分量：  v·C  -  1·B  =  v·C - B

   第二个分量：  1·A  -  u·C  =  A - u·C

   第三个分量：  u·B  -  v·A
```

## 3.3 从两个分量得到两个方程

**第一个分量 = 0：**

```
   v·C - B  =  0
```

代入 B 和 C：

```
   v·(h31·X + h32·Y + h33)  -  (h21·X + h22·Y + h23)  =  0
```

把每一项按未知量 h21, h22, h23, h31, h32, h33 整理：

```
   -X·h21  -  Y·h22  -  1·h23  +  v·X·h31  +  v·Y·h32  +  v·h33  =  0
```

写成行向量乘列向量 h（其中 h = (h11, h12, h13, h21, h22, h23, h31, h32, h33) 的转置）：

```
   ★   [ 0   0   0   -X   -Y   -1   v·X   v·Y   v ] · h  =  0
```

**第二个分量 = 0：**

```
   A - u·C  =  0
```

代入 A 和 C：

```
   (h11·X + h12·Y + h13)  -  u·(h31·X + h32·Y + h33)  =  0
```

整理：

```
   X·h11  +  Y·h12  +  1·h13  -  u·X·h31  -  u·Y·h32  -  u·h33  =  0
```

写成行向量：

```
   ★   [ X   Y   1   0   0   0   -u·X   -u·Y   -u ] · h  =  0
```

**注意第三个分量 u·B - v·A = 0 不是独立的**，
它是前两个方程的线性组合（可以用前两式乘以适当系数相加得到），所以丢弃。

## 3.4 组装成矩阵方程

每个点给出两行。把这两个行向量上下叠起来，记作 Ai：

```
           [  0   0   0   -X   -Y   -1    v·X    v·Y    v ]      ← 第 1 个分量
   Ai  =   [                                                ]
           [  X   Y   1    0    0    0   -u·X   -u·Y   -u ]      ← 第 2 个分量
```

m 个点堆叠：

```
        [ A1 ]
        [ A2 ]
   A =  [ .. ]        维数：2m 行，9 列
        [    ]
        [ Am ]
```

得到齐次线性方程组：

```
   ★   A · h  =  0
```

## 3.5 用 SVD 求解

A·h = 0 要的是**非零解**。做法：

```
   对 A 做奇异值分解：   A  =  U · Σ · V^T
```

则 h 取 V 的**最后一列**（对应最小奇异值的右奇异向量）：

```
   ★   h  =  V 的最后一列
```

然后重排成 3×3：

```
        [ h[0]  h[1]  h[2] ]
   H =  [ h[3]  h[4]  h[5] ]
        [ h[6]  h[7]  h[8] ]
```

（这里 h[k] 表示向量 h 的第 k 个元素，从 0 开始编号，对应 Python 的索引。）

**为什么是最后一列**：奇异值代表那个方向被拉伸的倍数，
最小奇异值对应的方向就是 A 几乎"压没了"的方向，
也就是让 ‖A·h‖ 最小的非零 h。

## 3.6 Hartley 归一化（必须做）

### 问题

棋盘角点像素可能是 (823, 617)，而板的坐标可能是 (0.02, 0.04)。
A 的各列量级差上百万倍，计算机算出来全是舍入误差。

### 图像点的归一化

**第一步：算重心**

```
   cu  =  (1/m) · Σ ui          （所有点 u 坐标的平均）

   cv  =  (1/m) · Σ vi          （所有点 v 坐标的平均）
```

**第二步：算平均距离并求缩放系数**

```
   先算每个点到重心的距离：  di  =  √( (ui - cu)² + (vi - cv)² )

   平均距离：               dbar  =  (1/m) · Σ di

   缩放系数：               s  =  √2 / dbar
```

（√2 是 Hartley 建议的目标平均距离，也可以取 1，效果类似。）

**第三步：构造归一化矩阵 T**

```
           [ s   0   -s·cu ]
   T  =    [ 0   s   -s·cv ]
           [ 0   0      1  ]
```

**验证**：把归一化作用到点上：

```
   T · (u, v, 1)  =  ( s·u - s·cu ,  s·v - s·cv ,  1 )
                   =  ( s·(u - cu) ,  s·(v - cv) ,  1 )
```

确实是把重心平移到原点，再整体缩放 s 倍。

**第四步：板的点也做同样处理**，得到矩阵 S。

（因为板的坐标通常量级比较整齐，实践中可以跳过，但加上更保险。）

### 求解与还原

用归一化后的点求出的单应矩阵记作 H'，则：

```
   p'  =  T · p            （归一化后的像素）

   M'  =  S · M            （归一化后的板坐标）

   p'  ~  H' · M'
```

代入：

```
   T·p  ~  H' · S·M
```

两边左乘 T 的逆：

```
   p  ~  T^(-1) · H' · S · M
```

对比 p ~ H·M，得到还原公式：

```
   ★   H  =  T^(-1) · H' · S
```

**T 的逆**（因为 T 是上三角，逆很好求）：

```
                [ 1/s    0     cu ]
   T^(-1)  =    [  0    1/s    cv ]
                [  0     0      1 ]
```

**验证 T · T^(-1) = I 的 (1,3) 位置**：

```
   s·cu + 0·cv + (-s·cu)·1  =  s·cu - s·cu  =  0       对上了
```

# 第 4 章　从单应建立内参约束

## 4.1 引入 λ

由第 2.2 节，H 和 K·[r1 r2 t] 相差一个尺度。写成：

```
   H  =  ξ · K · [ r1  r2  t ]         （ξ 是某个非零标量）
```

两边左乘 ξ 的倒数再左乘 K 的逆：

```
   [ r1  r2  t ]  =  (1/ξ) · K^(-1) · H
```

记 λ = 1/ξ：

```
   ★   [ r1  r2  t ]  =  λ · K^(-1) · H
```

按列拆开（这是后面最常用的形式）：

```
   ★   r1  =  λ · K^(-1) · h1

   ★   r2  =  λ · K^(-1) · h2

   ★   t   =  λ · K^(-1) · h3
```

**现在右边只剩 K 和标量 λ，外参 t 已经完全转到左边了。**

## 4.2 两条正交约束的完整推导

R 是旋转矩阵，列向量满足两条性质：

```
   性质 1：  r1 和 r2 垂直       即  r1 与 r2 的内积 = 0

   性质 2：  r1 和 r2 长度都是 1  即  r1 与 r1 的内积 = r2 与 r2 的内积
```

### 约束一：垂直

从 r1 与 r2 的内积等于零出发：

```
   (r1 的转置) · r2  =  0
```

代入 r1 = λ·K^(-1)·h1，r2 = λ·K^(-1)·h2：

```
   ( λ·K^(-1)·h1 的转置 ) · ( λ·K^(-1)·h2 )  =  0
```

用转置的乘积法则 (A·B) 的转置 = B 的转置 · A 的转置：

```
   λ · h1 的转置 · ( K^(-1) 的转置 ) · λ · K^(-1) · h2  =  0
```

把标量 λ² 提到最前面：

```
   λ² · h1 的转置 · ( K^(-1) 的转置 · K^(-1) ) · h2  =  0
```

**定义 B**：

```
   ★   B  =  ( K^(-1) 的转置 ) · K^(-1)
```

因为 λ ≠ 0，可以约掉 λ²，得到第一条约束：

```
   ★★★   h1 的转置 · B · h2  =  0
```

### 约束二：长度相等

从 r1 与 r1 的内积等于 r2 与 r2 的内积出发：

```
   (r1 的转置) · r1  -  (r2 的转置) · r2  =  0
```

代入同样处理：

```
   λ² · h1 的转置 · B · h1  -  λ² · h2 的转置 · B · h2  =  0
```

约掉 λ²：

```
   h1 的转置 · B · h1  -  h2 的转置 · B · h2  =  0
```

即：

```
   ★★★   h1 的转置 · B · h1  =  h2 的转置 · B · h2
```

**这就是全部的魔法**：

- 每张图给 2 个方程
- 方程里只有 B（也就是只有内参 K）
- **和外参 R, t 完全无关**

所以无论你怎么摆标定板，这 2 个方程都成立。

## 4.3 B 的性质与自由度

B = (K 的逆转置) · (K 的逆)。

**性质一：B 是对称的。** 证明：

```
   B 的转置  =  ( (K 的逆转置) · (K 的逆) ) 的转置

              =  ( K 的逆 ) 的转置 · ( K 的逆转置 ) 的转置

              =  (K 的逆转置) · (K 的逆)

              =  B
```

（用了 (A·B) 的转置 = B 的转置 · A 的转置，以及转置的转置等于自己。）

所以 B 有 6 个独立元素：

```
        [ B11   B12   B13 ]
   B =  [ B12   B22   B23 ]
        [ B13   B23   B33 ]
```

**性质二：B 只确定到相差一个尺度。**
因为 K 乘任意常数 k 时，B 变成 B / k²，但约束方程右端是 0，不受影响。

所以独立自由度 = 6 - 1 = **5**。

而内参 K 也正好是 5 个自由度（α, β, γ, u0, v0）。

**数字对上，这个方案是可行的。**

# 第 5 章　B 矩阵的显式计算

这一章把 B 的六个元素用内参完全写出来，供后面反解使用。

## 5.1 记号的简化

由第 1.4 节，K 的逆是：

```
               [ a   b   c ]
   K^(-1)  =   [ 0   d   e ]
               [ 0   0   1 ]
```

其中（**这五个式子后面反复用**）：

```
   a  =  1 / α

   b  =  -γ / (α·β)

   c  =  (γ·v0 - β·u0) / (α·β)

   d  =  1 / β

   e  =  -v0 / β
```

## 5.2 计算 K 的逆转置

K 的逆是上三角，转置之后变成下三角：

```
                      [ a   0   0 ]
   (K 的逆) 的转置 =  [ b   d   0 ]
                      [ c   e   1 ]
```

## 5.3 矩阵乘法 B = 下三角 乘 上三角

```
        [ a   0   0 ]   [ a   b   c ]
   B =  [ b   d   0 ] · [ 0   d   e ]
        [ c   e   1 ]   [ 0   0   1 ]
```

**逐行计算：**

**第 1 行**（取左边第 1 行 (a, 0, 0) 分别乘右边各列）：

```
   B11  =  a·a + 0·0 + 0·0  =  a²

   B12  =  a·b + 0·d + 0·0  =  a·b

   B13  =  a·c + 0·e + 0·1  =  a·c
```

**第 2 行**（取左边第 2 行 (b, d, 0)）：

```
   B21  =  b·a + d·0 + 0·0  =  a·b          （等于 B12，对称性体现）

   B22  =  b·b + d·d + 0·0  =  b² + d²

   B23  =  b·c + d·e + 0·1  =  b·c + d·e
```

**第 3 行**（取左边第 3 行 (c, e, 1)）：

```
   B31  =  c·a + e·0 + 1·0  =  a·c          （等于 B13）

   B32  =  c·b + e·d + 1·0  =  b·c + d·e    （等于 B23）

   B33  =  c·c + e·e + 1·1  =  c² + e² + 1
```

**结果矩阵**：

```
        [     a²         a·b            a·c      ]
   B =  [    a·b      b² + d²       b·c + d·e    ]
        [    a·c     b·c + d·e     c² + e² + 1   ]
```

## 5.4 代回 α, β, γ, u0, v0

**B11**：

```
   B11  =  a²  =  (1/α)²  =  1 / α²
```

**B12**：

```
   B12  =  a·b  =  (1/α) · ( -γ/(α·β) )  =  -γ / (α²·β)
```

**B13**：

```
   B13  =  a·c  =  (1/α) · ( (γ·v0 - β·u0)/(α·β) )

               =  (γ·v0 - β·u0) / (α²·β)
```

**B22**：

```
   B22  =  b² + d²

        =  ( -γ/(α·β) )²  +  ( 1/β )²

        =  γ²/(α²·β²)  +  1/β²

        =  γ²/(α²·β²)  +  α²/(α²·β²)          （第二项上下同乘 α²）

        =  (γ² + α²) / (α²·β²)
```

**B23**：

```
   B23  =  b·c + d·e
```

先分别算两项：

```
   b·c  =  ( -γ/(α·β) ) · ( (γ·v0 - β·u0)/(α·β) )

        =  -γ·(γ·v0 - β·u0) / (α²·β²)

        =  ( -γ²·v0 + γ·β·u0 ) / (α²·β²)

   d·e  =  ( 1/β ) · ( -v0/β )

        =  -v0 / β²

        =  -α²·v0 / (α²·β²)                   （上下同乘 α²）
```

相加：

```
   B23  =  ( -γ²·v0 + γ·β·u0 - α²·v0 ) / (α²·β²)
```

把含 v0 的项合并：

```
   ★   B23  =  ( γ·β·u0  -  v0·(γ² + α²) ) / (α²·β²)
```

**B33**：

```
   B33  =  c² + e² + 1
```

分别算：

```
   c²  =  (γ·v0 - β·u0)² / (α²·β²)

   e²  =  ( -v0/β )²  =  v0²/β²  =  α²·v0² / (α²·β²)

   1   =  α²·β² / (α²·β²)
```

相加（三项通分到 α²·β²）：

```
   ★   B33  =  ( (γ·v0 - β·u0)²  +  α²·v0²  +  α²·β² ) / (α²·β²)
```

## 5.5 六个元素的汇总表

**这是全文最重要的一张表，后面的反解全靠它。**

```
   B11  =  1 / α²

   B12  =  -γ / (α²·β)

   B13  =  (γ·v0 - β·u0) / (α²·β)

   B22  =  (γ² + α²) / (α²·β²)

   B23  =  ( γ·β·u0 - v0·(γ² + α²) ) / (α²·β²)

   B33  =  ( (γ·v0 - β·u0)² + α²·v0² + α²·β² ) / (α²·β²)
```

**注意**：这六个数都有一个共同的分母结构，都含有 1/(α²·β²) 或 1/(α²·β)。
这是后面能把 α, β 单独提出来开根号的原因。

# 第 6 章　线性方程组 V 乘 b 等于 0

## 6.1 把 B 向量化

定义 6 维列向量 b（**顺序是约定，必须记牢**）：

```
         [ B11 ]
         [ B12 ]
         [ B22 ]
   b  =  [ B13 ]
         [ B23 ]
         [ B33 ]
```

**为什么是这个顺序**：先走主对角线（B11, B22, B33），
非对角元按"上三角从左到右、从上到下"插入，且 B12 在 B22 之前、B13 在 B23 之前。

（论文里用的就是这个顺序。顺序错了后面全部对不上。）

## 6.2 推导 v(ij) 的定义

目标：把 h(i) 的转置 · B · h(j) 写成 (某个 6 维向量) 的转置 · b 的形式。

**从定义出发，完全展开。**

设

```
   h(i)  =  ( h(i)1, h(i)2, h(i)3 )

   h(j)  =  ( h(j)1, h(j)2, h(j)3 )
```

先算 B · h(j)：

```
   B · h(j)  =  ( B11·h(j)1 + B12·h(j)2 + B13·h(j)3 ,

                 B12·h(j)1 + B22·h(j)2 + B23·h(j)3 ,

                 B13·h(j)1 + B23·h(j)2 + B33·h(j)3 )
```

（用了 B 的对称性：B21 = B12，B31 = B13，B32 = B23。）

再与 h(i) 做内积：

```
   h(i) 的转置 · B · h(j)

     =  h(i)1 · ( B11·h(j)1 + B12·h(j)2 + B13·h(j)3 )
      + h(i)2 · ( B12·h(j)1 + B22·h(j)2 + B23·h(j)3 )
      + h(i)3 · ( B13·h(j)1 + B23·h(j)2 + B33·h(j)3 )
```

**按 B 的六个元素重新分组**：

```
   B11 的系数：   h(i)1 · h(j)1

   B12 的系数：   h(i)1 · h(j)2  +  h(i)2 · h(j)1
                  （第 1 行第 2 项 + 第 2 行第 1 项）

   B22 的系数：   h(i)2 · h(j)2

   B13 的系数：   h(i)1 · h(j)3  +  h(i)3 · h(j)1
                  （第 1 行第 3 项 + 第 3 行第 1 项）

   B23 的系数：   h(i)2 · h(j)3  +  h(i)3 · h(j)2
                  （第 2 行第 3 项 + 第 3 行第 2 项）

   B33 的系数：   h(i)3 · h(j)3
```

把这些系数按 b 的顺序排成向量 v(ij)：

```
                [ h(i)1 · h(j)1              ]
                [ h(i)1·h(j)2 + h(i)2·h(j)1    ]
   v(ij)  =     [ h(i)2 · h(j)2              ]
                [ h(i)1·h(j)3 + h(i)3·h(j)1    ]
                [ h(i)2·h(j)3 + h(i)3·h(j)2    ]
                [ h(i)3 · h(j)3              ]
```

于是得到**关键恒等式**：

```
   ★   h(i) 的转置 · B · h(j)  =  v(ij) 的转置 · b
```

## 6.3 两条约束的向量化

**约束一**（h1 的转置 · B · h2 = 0），取 i = 1, j = 2：

```
   v(12) 的转置 · b  =  0
```

**约束二**（h1 的转置 · B · h1 = h2 的转置 · B · h2）：

先移项成"右边等于 0"：

```
   h1 的转置 · B · h1  -  h2 的转置 · B · h2  =  0
```

分别向量化：

```
   ( v(11) 的转置  -  v(22) 的转置 ) · b  =  0
```

即：

```
   ( v(11) - v(22) ) 的转置 · b  =  0
```

## 6.4 组装 V 矩阵

**每张图贡献两行**：

```
        [     v(12) 的转置          ]      ← 来自正交约束
        [ ( v(11) - v(22) ) 的转置  ]      ← 来自等长约束
```

n 张图从上到下堆叠：

```
        [     v(12) 的转置          ]      ← 第 1 张图
        [ ( v(11) - v(22) ) 的转置  ]
        [     v(12) 的转置          ]      ← 第 2 张图
   V =  [ ( v(11) - v(22) ) 的转置  ]
        [          ...              ]
        [     v(12) 的转置          ]      ← 第 n 张图
        [ ( v(11) - v(22) ) 的转置  ]
```

**维数**：2n 行，6 列。

（注意每张图的 v(12)、v(11)、v(22) 是用**该图自己的** H 算出来的，
所以每一对行都不一样。这里的下标 1、2 指的是 H 的**列**，不是图的编号。）

得到：

```
   ★   V · b  =  0
```

## 6.5 张数要求与补约束

b 有 6 个未知数，去掉整体尺度后是 **5 个**。

| 张数 n | 方程数 2n | 缺几个 | 补救办法 |
|---|---|---|---|
| 3 | 6 | 够（6 ≥ 6） | 直接 SVD |
| 2 | 4 | 缺 1 | 加 γ = 0，即令 B12 = 0 |
| 1 | 2 | 缺 3 | 加 u0, v0 已知（取图像中心） |

**γ = 0 的约束怎么加**：B12 = 0 意味着 b 的第 2 个分量为 0，即

```
   [ 0   1   0   0   0   0 ] · b  =  0
```

在 V 的下面加这一行。

**主点已知的约束怎么加**：
u0, v0 已知时，B13 = 0 且 B23 = 0，即

```
   [ 0   0   0   1   0   0 ] · b  =  0        （B13 = 0）

   [ 0   0   0   0   1   0 ] · b  =  0        （B23 = 0）
```

在 V 的下面加这两行。

**求解方法**：对 V 做 SVD，b 取 V 的最后一列（最小奇异向量）。

```
   V  =  U · Σ · VT

   b  =  VT 的最后一列
```

# 第 7 章　从 B 反解内参（逐步推导）

这是论文附录 A 的内容。**论文只给了结果，这里把每一步代数都写出来。**

## 7.1 先说明尺度问题

算法解出来的 b（以及由它重排成的 B）**只确定到相差一个正数倍数**。

设真实关系是：

```
   B  =  η · B(理论)
```

其中 η 是未知正数，B(理论) 就是第 5.5 节那张表里列出的表达式。

（η 一定为正，因为 B 是正定矩阵。）

**结论先行**：下面推出的每个公式**都不含 η**，所以可以放心算。

## 7.2 预备：四个关键组合量

在推导 v0 和 λ 之前，先算出四个组合量。**这四个计算是全部推导的基础。**

### 组合量 (1)：B11·B22 - B12²

用第 5.5 节的表达式（先按理论值算）：

```
   B11 · B22  =  (1/α²) · ( (γ² + α²)/(α²·β²) )

              =  (γ² + α²) / (α⁴·β²)

   B12²       =  ( -γ/(α²·β) )²

              =  γ² / (α⁴·β²)
```

相减：

```
   B11·B22 - B12²  =  ( γ² + α² - γ² ) / (α⁴·β²)

                   =  α² / (α⁴·β²)

   ★   =  1 / (α²·β²)
```

### 组合量 (2)：B12·B13 - B11·B23

先分别算：

```
   B12 · B13  =  ( -γ/(α²·β) ) · ( (γ·v0 - β·u0)/(α²·β) )

              =  -γ·(γ·v0 - β·u0) / (α⁴·β²)

              =  ( -γ²·v0 + γ·β·u0 ) / (α⁴·β²)
```

```
   B11 · B23  =  (1/α²) · ( γ·β·u0 - v0·(γ² + α²) ) / (α²·β²)

              =  ( γ·β·u0 - γ²·v0 - α²·v0 ) / (α⁴·β²)
```

（把 v0·(γ² + α²) 展开成 γ²·v0 + α²·v0。）

相减：

```
   B12·B13 - B11·B23

     =  [ -γ²·v0 + γ·β·u0  -  γ·β·u0 + γ²·v0 + α²·v0 ] / (α⁴·β²)
```

**注意四项两两抵消**：-γ²·v0 和 +γ²·v0 抵消，+γ·β·u0 和 -γ·β·u0 抵消。

```
     =  α²·v0 / (α⁴·β²)

   ★   =  v0 / (α²·β²)
```

**这个抵消非常漂亮，是 v0 能被单独解出来的原因。**

### 组合量 (3)：B13² + v0·(B12·B13 - B11·B23)

```
   B13²  =  (γ·v0 - β·u0)² / (α⁴·β²)

   v0 · (B12·B13 - B11·B23)  =  v0 · v0 / (α²·β²)

                             =  v0²·α² / (α⁴·β²)     （上下同乘 α²）
```

相加：

```
   ★   =  [ (γ·v0 - β·u0)²  +  α²·v0² ] / (α⁴·β²)
```

### 组合量 (4)：B33

直接由第 5.5 节：

```
   ★   B33  =  [ (γ·v0 - β·u0)²  +  α²·v0²  +  α²·β² ] / (α²·β²)
```

## 7.3 推导 v0 的公式

**目标**：从组合量 (1) 和 (2) 得到 v0。

因为 (2) 等于 v0/(α²β²)，(1) 等于 1/(α²β²)，
两者相除时分母 α²β² 消掉：

```
   (2)      v0 / (α²·β²)
   -----  = ---------------  =  v0
   (1)      1 / (α²·β²)
```

所以：

```
   ★★★   v0  =  ( B12·B13 - B11·B23 ) / ( B11·B22 - B12² )
```

**尺度不变的验证**：若 B 换成 η·B，则分子分母都乘上 η²，商不变。

## 7.4 推导 λ 的公式

**先定义 λ**（注意：这里的 λ 是第 7 章新引入的尺度量，和第 4 章的 λ 无关）：

```
   ★   λ  =  B33  -  [ 组合量 (3) ] / B11
```

**推导过程**：把 B33 和组合量 (3) 都写成分母为 α²·β² 的形式。

组合量 (3) 除以 B11：

```
   (3) / B11  =  [ (γ·v0 - β·u0)² + α²·v0² ] / (α⁴·β²)  除以  (1/α²)

              =  [ (γ·v0 - β·u0)² + α²·v0² ] / (α⁴·β²)  ×  α²

              =  [ (γ·v0 - β·u0)² + α²·v0² ] / (α²·β²)
```

B33 减去它：

```
   λ  =  [ (γ·v0 - β·u0)² + α²·v0² + α²·β² ] / (α²·β²)
       - [ (γ·v0 - β·u0)² + α²·v0²          ] / (α²·β²)
```

**分子的前两组项完全抵消**，只剩最后一项：

```
   λ  =  α²·β² / (α²·β²)

   ★★★   λ  =  1                    （对理论值 B 而言）
```

**对缩放后的 B = η·B(理论)**：

B33 变成 η·B33，组合量 (3) 里的 B13² 变成 η²·B13²，
而 v0·(B12B13 - B11B23) 里的 B12B13、B11B23 各乘 η，乘积乘 η²。
所以整个组合量 (3) 乘 η²，再除以 B11（乘 η）后整体变成 η 倍。

于是：

```
   λ  =  η·B33(理论)  -  η·(3)(理论)/B11(理论)

      =  η · [ B33(理论) - (3)(理论)/B11(理论) ]

      =  η · 1

   ★   λ  =  η
```

**结论：算出来的 λ 恰好就是那个未知尺度 η。**

这正是后面 α、β 公式能自动消掉 η 的原因。

## 7.5 推导 α 的公式

由第 5.5 节：

```
   B11  =  1 / α²
```

两边取倒数：

```
   1 / B11  =  α²
```

所以

```
   ★   α  =  √( 1 / B11 )
```

**但对缩放后的 B = η·B(理论)**，B11 = η/α²，直接开根号会得到 √(α²/η)，多了个 η。

用 7.4 节算出的 λ = η 来修正：

```
   λ / B11  =  η / (η/α²)  =  α²
```

所以：

```
   ★★★   α  =  √( λ / B11 )
```

## 7.6 推导 β 的公式

由组合量 (1)：

```
   B11·B22 - B12²  =  1 / (α²·β²)
```

两边取倒数：

```
   1 / ( B11·B22 - B12² )  =  α²·β²
```

再乘上 α²：

```
   α² / ( B11·B22 - B12² )  =  α⁴·β²      ← 这样还不对
```

换个思路。我们要的是 β²。注意到：

```
   α²·β²  =  1 / ( B11·B22 - B12² )
```

所以

```
   β²  =  1 / [ α² · ( B11·B22 - B12² ) ]
```

把 α² = λ/B11 代入：

```
   β²  =  1 / [ (λ/B11) · ( B11·B22 - B12² ) ]

       =  B11 / [ λ · ( B11·B22 - B12² ) ]
```

取倒数（等价变形，方便写成论文的形式）：

```
   ★★★   β  =  √( λ · B11 / ( B11·B22 - B12² ) )
```

**尺度不变的验证**：
分子 λ·B11 = η · (η/α²) = η²/α²。
分母 B11B22 - B12² = η²/(α²β²)。
相除 = (η²/α²) · (α²β²/η²) = β²。
开根号得 β。**η 消掉了。**

## 7.7 推导 γ 的公式

由第 5.5 节：

```
   B12  =  -γ / (α²·β)
```

两边乘以 α²·β：

```
   B12 · α² · β  =  -γ
```

所以

```
   γ  =  -B12 · α² · β
```

**但对缩放后的 B**，B12 = η·(-γ/(α²β))，
直接算会得到 η·γ，多了个 η。用 λ = η 修正：

```
   ★★★   γ  =  -B12 · α² · β / λ
```

**尺度不变的验证**：
分子 = η·(-γ/(α²β)) · α² · β = -η·γ。
再除以 λ = η，得 -γ。

**注意**：γ 的公式里需要用到 α 和 β，所以必须在 α、β 求出之后再算。

## 7.8 推导 u0 的公式

由第 5.5 节：

```
   B13  =  (γ·v0 - β·u0) / (α²·β)
```

两边乘以 α²/λ：

```
   B13 · α² / λ  =  (γ·v0 - β·u0) / (α²·β) · α² / λ

                 =  (γ·v0 - β·u0) / (β · λ)
```

对理论值（λ = 1）：

```
   B13 · α² / λ  =  (γ·v0 - β·u0) / β

                 =  γ·v0/β  -  u0
```

移项：

```
   u0  =  γ·v0/β  -  B13 · α² / λ
```

写成最终形式：

```
   ★★★   u0  =  γ·v0/β  -  B13 · α² / λ
```

**尺度不变的验证**：
B13 乘 η，α² = λ/B11 = (η)/(η/α²) = α²（不变），λ = η。
所以 B13·α²/λ = η·B13(理论)·α²/η = B13(理论)·α²。η 消掉了。

**注意**：u0 的公式需要 γ 和 β，所以必须在它们之后算。

## 7.9 计算顺序（重要）

五个参数的求解有**严格的依赖顺序**，不能颠倒：

```
   第 1 步：  v0      ←  只用 B 的元素

   第 2 步：  λ       ←  用 B 的元素 和 v0

   第 3 步：  α       ←  用 B11 和 λ

   第 4 步：  β       ←  用 B 的元素和 λ

   第 5 步：  γ       ←  用 B12, α, β, λ

   第 6 步：  u0      ←  用 B13, α, λ, γ, v0, β
```

## 7.10 五个公式汇总

**把这一页抄下来，这就是张氏标定法的核心。**

```
   ★   v0  =  ( B12·B13 - B11·B23 ) / ( B11·B22 - B12² )

   ★   λ   =  B33 - [ B13² + v0·( B12·B13 - B11·B23 ) ] / B11

   ★   α   =  √( λ / B11 )

   ★   β   =  √( λ · B11 / ( B11·B22 - B12² ) )

   ★   γ   =  - B12 · α² · β / λ

   ★   u0  =  γ · v0 / β  -  B13 · α² / λ
```

**注意 γ 和 u0 在论文中常写作**（当 γ = 0 时，也就是大多数实际情形）：

```
   γ   =  0

   u0  =  - B13 · α² / λ
```

（因为 γ = 0 时，u0 公式里的第一项 γ·v0/β 消失。）

# 第 8 章　外参的求解

## 8.1 确定 λ

回到第 4.1 节：

```
   r1  =  λ · K^(-1) · h1
```

利用 ‖r1‖ = 1：

```
   ‖ λ · K^(-1) · h1 ‖  =  1
```

把绝对值提出：

```
   |λ| · ‖ K^(-1) · h1 ‖  =  1
```

所以：

```
   |λ|  =  1 / ‖ K^(-1) · h1 ‖
```

取正号（因为 r1 和 h1 方向应当一致）：

```
   ★   λ  =  1 / ‖ K^(-1) · h1 ‖
```

**同理**，由 ‖r2‖ = 1 也可以得到：

```
   λ  =  1 / ‖ K^(-1) · h2 ‖
```

**两个值理论上应该相等**，实践中取平均更稳健：

```
   ★   λ  =  2 / ( ‖ K^(-1)·h1‖  +  ‖ K^(-1)·h2‖ )
```

（注意：这里的 λ 是第 8 章新引入的，和第 4 章、第 7 章的 λ 都不是同一个量，
只是习惯上都叫 λ。论文里是这么写的，容易混淆，心里清楚即可。）

## 8.2 三个外参的公式

```
   ★   r1  =  λ · K^(-1) · h1

   ★   r2  =  λ · K^(-1) · h2

   ★   r3  =  r1 × r2                 （叉乘，因为旋转矩阵三列正交）

   ★   t   =  λ · K^(-1) · h3
```

**向量的长度**：‖v‖ = √(v1² + v2² + v3²)。

**为什么 r3 用叉乘而不是 λ·K^(-1)·h3**：
因为 r3 应该是与 r1、r2 都垂直的单位向量，而叉乘恰好给出这个。
用 h3 反算会引入额外误差。

## 8.3 正交化（把 Q 掰回合法旋转矩阵）

**问题**：由于角点检测误差，算出的 r1, r2 不会精确垂直、精确长度为 1。
直接拼成矩阵当旋转矩阵用会有问题（比如行列式不等于 1）。

**解法**：求"最接近的合法旋转矩阵"。步骤：

**第 1 步：拼成矩阵 Q**

```
        [              ]
   Q =  [  r1   r2   r3 ]        维数 3×3
        [              ]
```

**第 2 步：对 Q 做奇异值分解**

```
   Q  =  U · Σ · V 的转置
```

**第 3 步：直接取**

```
   ★   R  =  U · V 的转置
```

**第 4 步：检查行列式符号**

算 R 的行列式 det(R)。如果 det(R) = -1（是镜像而不是旋转），则修正：

```
   把 Σ 的第三个对角元改成 -1，重新算 R = U · Σ(修正后) · V 的转置
```

或者等价地：把 V 的转置的第三行乘以 -1 再乘。

**这个操作的数学名字**：正交 Procrustes 问题。

它解的是：在所有正交矩阵中，找使 ‖Q - R‖ 最小的那个 R。

# 第 9 章　径向畸变的求解

## 9.1 畸变模型

设 (xn, yn) 是**理想**归一化坐标（针孔模型应该得到的位置），
(xd, yd) 是**实际观测**到的归一化坐标。

模型：

```
   xd  =  xn · ( 1 + k1·r² + k2·r⁴ )

   yd  =  yn · ( 1 + k1·r² + k2·r⁴ )

   其中  r²  =  xn² + yn²
```

**人话**：括号里那个因子只跟半径 r 有关，
所以**画面中心不变形，越靠边变形越大**。

## 9.2 怎么得到 (xn, yn) 和 (xd, yd)

**观测坐标 (xd, yd)**：由检测到的像素直接换算。

```
   xd  =  ( u 检测值  -  u0 ) / α

   yd  =  ( v 检测值  -  v0 ) / β
```

（这里假设 γ = 0。若 γ 不为 0，需要解一个 2×2 线性方程组。）

**理想坐标 (xn, yn)**：由该图的单应矩阵 H 投影得到。

```
   ( xn·w , yn·w , w )  =  K^(-1) · H · ( X, Y, 1 )
```

然后

```
   xn  =  (xn·w) / w

   yn  =  (yn·w) / w
```

（w 是第三分量，用来做归一化。）

## 9.3 移项成线性形式

把模型改写：

```
   xd - xn  =  xn · r² · k1  +  xn · r⁴ · k2

   yd - yn  =  yn · r² · k1  +  yn · r⁴ · k2
```

**k1 和 k2 现在是一次项了**，所以是线性方程组。

每个点写成矩阵形式：

```
   [ xn·r²    xn·r⁴ ] [ k1 ]   [ xd - xn ]
   [                ] [    ] = [         ]
   [ yn·r²    yn·r⁴ ] [ k2 ]   [ yd - yn ]
```

## 9.4 堆叠求解

n 张图、每张 m 个点，共 2nm 个方程，2 个未知数。

记左边矩阵为 D（2nm 行 2 列），右边向量为 d（2nm 行），则：

```
   D · k  =  d
```

**最小二乘解**：

```
   ★   k  =  ( D 的转置 · D )^(-1) · ( D 的转置 · d )
```

其中 k = (k1, k2) 的转置。

**为什么用最小二乘而不是直接求逆**：D 不是方阵（行数远大于列数），
不能直接求逆，只能求"使 ‖D·k - d‖ 最小的那个 k"。

**补丁**：实践中 k1 和 u0, v0 强耦合，
所以通常把 k1, k2 加入第 10 章的非线性优化一起调，而不是单独解。

# 第 10 章　最大似然精化

## 10.1 目标函数

前面的步骤最小化的是**代数误差**（‖A·h‖、‖V·b‖），
不是真正关心的几何误差。

**正确的目标**（假设像素噪声独立同分布、服从正态分布）：

```
   ★   最小化  Σ   Σ   ‖ p(检测) - p(模型) ‖²
                i   j      ij         ij
```

其中：

- i 遍历 n 张图
- j 遍历每张图的 m 个角点
- p(检测) 是角点检测算法给出的像素坐标
- p(模型) 是由当前参数 K, k1, k2, Ri, ti 和板坐标 Mj 投影算出的像素坐标

**p(模型) 的完整计算链**：

```
   第 1 步：  Xc  =  Ri · Mj + ti
              即 (Xc, Yc, Zc) = Ri · (X, Y, Z) + (ti1, ti2, ti3)

   第 2 步：  xn  =  Xc / Zc

              yn  =  Yc / Zc

   第 3 步：  r²  =  xn² + yn²

              xd  =  xn · ( 1 + k1·r² + k2·r⁴ )

              yd  =  yn · ( 1 + k1·r² + k2·r⁴ )

   第 4 步：  u  =  α·xd + γ·yd + u0

              v  =  β·yd + v0
```

**未知量总数**：

```
   5 个内参  +  2 个畸变  +  6n 个外参  =  7 + 6n
```

（10 张图就是 67 个未知数。）

## 10.2 雅可比矩阵的完整推导

用链式法则，一层一层往回乘。

### 链条结构

```
   (R, t)  -->  Xc  -->  (xn, yn)  -->  (xd, yd)  -->  (u, v)
              block 2      block 3        block 4      block 1
```

（编号按"从输出往回"的顺序，方便和相乘顺序对应。）

### Block 1：像素对畸变后归一化坐标

由 u = α·xd + γ·yd + u0，v = β·yd + v0：

```
   ∂u/∂α   =  xd          ∂v/∂α   =  0
   ∂u/∂β   =  0           ∂v/∂β   =  yd
   ∂u/∂γ   =  yd          ∂v/∂γ   =  0
   ∂u/∂u0  =  1           ∂v/∂u0  =  0
   ∂u/∂v0  =  0           ∂v/∂v0  =  1
```

写成矩阵（这是"像素对 (xd, yd)"的 2×2 块）：

```
              [ α   γ ]
   Block 1 =  [       ]
              [ 0   β ]
```

### Block 2：畸变后归一化坐标对理想归一化坐标

由 xd = xn·(1 + k1·r² + k2·r⁴)，其中 r² = xn² + yn²。

**先算 ∂r²/∂xn 和 ∂r²/∂yn**：

```
   r²  =  xn² + yn²

   ∂r²/∂xn  =  2·xn

   ∂r²/∂yn  =  2·yn
```

**再算 ∂xd/∂xn**（用乘积法则）：

```
   ∂xd/∂xn  =  ∂/∂xn [ xn · (1 + k1·r² + k2·r⁴) ]

            =  1 · (1 + k1·r² + k2·r⁴)  +  xn · ∂/∂xn[ 1 + k1·r² + k2·r⁴ ]

            =  (1 + k1·r² + k2·r⁴)  +  xn · ( k1·2·xn + k2·4·r²·xn )

            =  (1 + k1·r² + k2·r⁴)  +  2·k1·xn²  +  4·k2·xn²·r²
```

（推导里用到 ∂r⁴/∂xn，展开一下：

```
   ∂(r⁴)/∂xn  =  4·r³ · ∂r/∂xn

   而  r = √(xn² + yn²)，所以  ∂r/∂xn = xn / r

   因此  ∂(r⁴)/∂xn  =  4·r³ · (xn/r)  =  4·xn·r²
```

代回上式，第二项就是 xn · ( k1·2·xn + k2·4·xn·r² )，
展开后正好是 2·k1·xn² + 4·k2·xn²·r²。) 

**∂xd/∂yn**：

```
   ∂xd/∂yn  =  xn · ∂/∂yn[ 1 + k1·r² + k2·r⁴ ]

            =  xn · ( k1·2·yn + k2·4·yn·r² )

            =  2·k1·xn·yn  +  4·k2·xn·yn·r²
```

**∂yd/∂xn**（对称）：

```
   ∂yd/∂xn  =  yn · ( k1·2·xn + k2·4·xn·r² )

            =  2·k1·xn·yn  +  4·k2·xn·yn·r²
```

**∂yd/∂yn**：

```
   ∂yd/∂yn  =  (1 + k1·r² + k2·r⁴)  +  2·k1·yn²  +  4·k2·yn²·r²
```

**Block 2 汇成矩阵**：

```
              [ ∂xd/∂xn   ∂xd/∂yn ]
   Block 2 =  [                    ]
              [ ∂yd/∂xn   ∂yd/∂yn ]
```

其中：

```
   ∂xd/∂xn  =  (1 + k1·r² + k2·r⁴) + 2·k1·xn² + 4·k2·xn²·r²

   ∂xd/∂yn  =  2·k1·xn·yn + 4·k2·xn·yn·r²

   ∂yd/∂xn  =  2·k1·xn·yn + 4·k2·xn·yn·r²

   ∂yd/∂yn  =  (1 + k1·r² + k2·r⁴) + 2·k1·yn² + 4·k2·yn²·r²
```

### Block 3：理想归一化坐标对相机坐标

由 xn = Xc/Zc，yn = Yc/Zc，用商的求导法则：

```
   ∂xn/∂Xc  =  1/Zc          ∂xn/∂Yc  =  0            ∂xn/∂Zc  =  -Xc/Zc²

   ∂yn/∂Xc  =  0             ∂yn/∂Yc  =  1/Zc         ∂yn/∂Zc  =  -Yc/Zc²
```

**Block 3 汇成矩阵**（2 行 3 列）：

```
              [ 1/Zc     0      -Xc/Zc² ]
   Block 3 =  [                         ]
              [   0    1/Zc     -Yc/Zc² ]
```

### Block 4：相机坐标对外参

**对平移 t**：

由 Xc = R·M + t，t 每增加一个单位，Xc 就增加一个单位：

```
   ∂Xc/∂t  =  I        （3×3 单位矩阵）
```

**对旋转**：这里用**扰动法**，不要直接对旋转矩阵求导。

设给旋转加一个微小的额外旋转 ω = (ω1, ω2, ω3)：

```
   Xc(新)  =  把 ω 作用到 Xc 上

           ≈  Xc  +  ω × Xc
```

把叉乘展开（用第 6 章的叉乘公式，注意是 ω × Xc 而不是 Xc × ω）：

```
   ω × Xc  =  ( ω2·Zc - ω3·Yc ,

                ω3·Xc - ω1·Zc ,

                ω1·Yc - ω2·Xc )
```

写成矩阵乘向量：

```
   ω × Xc  =  - [Xc]× · ω
```

其中 [Xc]× 是"反对称矩阵算子"：

```
                [   0    -Zc    Yc ]
   [Xc]×  =     [  Zc      0   -Xc ]
                [ -Yc     Xc     0 ]
```

**验证一下符号**：

```
   [Xc]× · ω  =  ( 0·ω1 - Zc·ω2 + Yc·ω3 ,

                   Zc·ω1 + 0·ω2 - Xc·ω3 ,

                  -Yc·ω1 + Xc·ω2 + 0·ω3 )

              =  ( -Zc·ω2 + Yc·ω3 ,  Zc·ω1 - Xc·ω3 ,  -Yc·ω1 + Xc·ω2 )
```

对比上面 ω × Xc 的结果 (ω2·Zc - ω3·Yc, ω3·Xc - ω1·Zc, ω1·Yc - ω2·Xc)，
确实每一项都差一个负号。

所以：

```
   ω × Xc  =  - [Xc]× · ω
```

因此：

```
   ★   ∂Xc/∂ω  =  - [Xc]×
```

**Block 4 汇成矩阵**（3 行 6 列，左 3 列是旋转，右 3 列是平移）：

```
   Block 4  =  [ -[Xc]×   |   I  ]
```

### 整体雅可比：把四个块按顺序相乘

**求 (u, v) 对 (R, t) 的偏导**（2 行 6 列）：

```
   ∂(u,v)/∂(R,t)  =  Block 1 · Block 2 · Block 3 · Block 4
```

即：

```
                  [ α  γ ]   [ ∂xd/∂xn  ∂xd/∂yn ]   [ 1/Zc    0    -Xc/Zc² ]   [              ]
   J  =  (2×6)    [      ] · [                   ] · [                      ] · [ -[Xc]×  |  I ]
                  [ 0  β ]   [ ∂yd/∂xn  ∂yd/∂yn ]   [   0   1/Zc   -Yc/Zc² ]   [              ]
```

**维数检查**：

```
   (2×2) · (2×2) · (2×3) · (3×6)  =  (2×6)          对上了
```

### 对畸变系数的偏导

```
   ∂u/∂k1  =  α·xn·r²  +  γ·yn·r²

   ∂u/∂k2  =  α·xn·r⁴  +  γ·yn·r⁴

   ∂v/∂k1  =  β·yn·r²

   ∂v/∂k2  =  β·yn·r⁴
```

（推导：xd 对 k1 的偏导是 xn·r²，yd 对 k1 的偏导是 yn·r²，
再经 Block 1 传上去即可。）

写成矩阵：

```
   ∂(u,v)/∂(k1,k2)  =  Block 1 · [ xn·r²   xn·r⁴ ]
                                  [              ]
                                  [ yn·r²   yn·r⁴ ]
```

### 对内参的偏导

```
   ∂(u,v)/∂(α, β, γ, u0, v0)
```

这是 2 行 5 列的矩阵：

```
        [ xd    0    yd    1    0 ]
        [                         ]
        [  0   yd     0    0    1 ]
```

（第一行是 ∂u 对各内参，第二行是 ∂v 对各内参。）

### 雅可比矩阵的组装

把所有残差（2nm 个）排成一个长向量 r，
把所有参数排成一个长向量 x，则雅可比 J 是：

```
   J  =  [ 对残差 1 的各参数偏导 ]
         [ 对残差 2 的各参数偏导 ]
         [         ...          ]
         [ 对残差 2nm 的各偏导  ]
```

维数：**(2nm) 行 × (7 + 6n) 列**。

**符号注意**：如果残差定义为 r = 观测 - 预测，
则 J 应该带上整体负号（或者统一在残差定义里处理）。

## 10.3 迭代求解

用第 8 章之前的闭式解作为初值，然后用 Levenberg-Marquardt 迭代：

```
   ( J 的转置 · J  +  μ · D ) · δ  =  - ( J 的转置 · r )

   其中  D  =  diag( J 的转置 · J )
```

每次迭代后 x ← x + δ，直到收敛。

# 第 11 章　完整算法流程

```
==========================================================
  阶段一：线性闭式解
==========================================================

  输入：n 张标定板图像，角点检测结果

  ---- 对每张图 i = 1 到 n ----

    第 1 步： Hartley 归一化
       算重心 (cu, cv)，算平均距离 dbar
       缩放系数  s = √2 / dbar
       构造 T（图像点）和 S（板点）

    第 2 步： DLT 求单应
       对每个点，按第 3.3 节构造 2 行
       堆成 A（2m 行 9 列）
       对 A 做 SVD，h = V 的最后一列
       重排成 3×3 得 H'
       还原：  Hi = T^(-1) · H' · S

  ---- 汇总所有图 ----

    第 3 步： 对每张图，由 Hi 算出 v(12), v(11), v(22)
             每张图贡献 2 行：
               第 2i-1 行：  v(12) 的转置
               第 2i   行：  ( v(11) - v(22) ) 的转置
             堆成 V（2n 行 6 列）
             （若 n = 2，补一行 B12 = 0；若 n = 1，补两行 B13 = B23 = 0）

    第 4 步： 对 V 做 SVD，b = V 的最后一列
             由 b 重排出 B（3×3 对称矩阵）

    第 5 步： 按第 7.9 节的顺序解内参
             v0  ->  λ  ->  α  ->  β  ->  γ  ->  u0

  ---- 解外参 ----

    第 6 步： 对每张图
             λi = 1 / ‖ K^(-1) · h1 ‖
             r1 = λi · K^(-1) · h1
             r2 = λi · K^(-1) · h2
             r3 = r1 × r2
             t  = λi · K^(-1) · h3
             对 Q = [r1 r2 r3] 做 SVD，取 R = U · V 的转置

  ---- 解畸变 ----

    第 7 步： 对每个点构造 2 行（第 9.4 节）
             堆成 D 和 d
             最小二乘解 k = ( D 转置 · D )^(-1) · ( D 转置 · d )

==========================================================
  阶段二：非线性精化
==========================================================

  第 8 步： 用上面的结果作初值

  第 9 步： 构造残差 r = 观测像素 - 模型投影像素

  第 10 步： 算雅可比 J（第 10.2 节的四个 Block 相乘）

  第 11 步： LM 迭代
            重复：
              解  ( J 转置 · J + μ·D ) · δ = - J 转置 · r
              试走一步，算增益比 ρ
              ρ > 0 则接受并减小 μ，否则拒绝并增大 μ
            直到收敛

  第 12 步： 输出最终 K, k1, k2, {Ri, ti}
            计算重投影误差 RMS 作验收（应达 0.1 到 0.3 像素）
```

# 附录 A　核心公式速查表

## A.1 相机模型

```
   s · (u, v, 1)  =  K · [ R | t ] · (X, Y, Z, 1)

        [ α   γ   u0 ]
   K =  [ 0   β   v0 ]
        [ 0   0    1 ]
```

## A.2 内参矩阵的逆

```
               [ 1/α   -γ/(α·β)   (γ·v0 - β·u0)/(α·β) ]
   K^(-1)  =   [  0       1/β            -v0/β         ]
               [  0        0               1           ]
```

## A.3 单应矩阵

```
   H  =  K · [ r1  r2  t ]

   s · (u, v, 1)  =  H · (X, Y, 1)

   (u, v, 1) × [ H · (X, Y, 1) ]  =  0
```

每个点的两行方程：

```
   [ 0   0   0   -X   -Y   -1    v·X    v·Y    v ] · h  =  0

   [ X   Y   1    0    0    0   -u·X   -u·Y   -u ] · h  =  0
```

## A.4 两条约束

```
   h1 的转置 · B · h2  =  0

   h1 的转置 · B · h1  =  h2 的转置 · B · h2

   B  =  ( K^(-1) 的转置 ) · K^(-1)
```

## A.5 B 的六个元素

```
   B11  =  1 / α²

   B12  =  -γ / (α²·β)

   B13  =  (γ·v0 - β·u0) / (α²·β)

   B22  =  (γ² + α²) / (α²·β²)

   B23  =  ( γ·β·u0 - v0·(γ² + α²) ) / (α²·β²)

   B33  =  ( (γ·v0 - β·u0)² + α²·v0² + α²·β² ) / (α²·β²)
```

## A.6 向量 v(ij)

```
                [ h(i)1 · h(j)1              ]
                [ h(i)1·h(j)2 + h(i)2·h(j)1    ]
   v(ij)  =     [ h(i)2 · h(j)2              ]
                [ h(i)1·h(j)3 + h(i)3·h(j)1    ]
                [ h(i)2·h(j)3 + h(i)3·h(j)2    ]
                [ h(i)3 · h(j)3              ]

   b  =  ( B11, B12, B22, B13, B23, B33 ) 的转置

   h(i) 的转置 · B · h(j)  =  v(ij) 的转置 · b
```

## A.7 约束矩阵 V

```
        [     v(12) 的转置          ]
   V =  [ ( v(11) - v(22) ) 的转置  ]      每张图两行，共 2n 行 6 列

   V · b  =  0
```

## A.8 从 B 反解内参（核心）

```
   v0  =  ( B12·B13 - B11·B23 ) / ( B11·B22 - B12² )

   λ   =  B33 - [ B13² + v0·( B12·B13 - B11·B23 ) ] / B11

   α   =  √( λ / B11 )

   β   =  √( λ · B11 / ( B11·B22 - B12² ) )

   γ   =  - B12 · α² · β / λ

   u0  =  γ · v0 / β  -  B13 · α² / λ
```

## A.9 外参

```
   λ  =  1 / ‖ K^(-1) · h1 ‖

   r1  =  λ · K^(-1) · h1

   r2  =  λ · K^(-1) · h2

   r3  =  r1 × r2

   t   =  λ · K^(-1) · h3

   正交化：  Q = [r1 r2 r3]，做 SVD  Q = U·Σ·V 转置，取  R = U · V 转置
```

## A.10 径向畸变

```
   xd  =  xn · ( 1 + k1·r² + k2·r⁴ )

   yd  =  yn · ( 1 + k1·r² + k2·r⁴ )

   r²  =  xn² + yn²

   [ xn·r²    xn·r⁴ ] [ k1 ]   [ xd - xn ]
   [                ] [    ] = [         ]
   [ yn·r²    yn·r⁴ ] [ k2 ]   [ yd - yn ]
```

## A.11 最大似然目标

```
   最小化  Σ  Σ  ‖ p(检测) - p(模型) ‖²
           i  j     ij         ij

   未知量：  5 个内参 + 2 个畸变 + 6n 个外参
```

# 附录 B　手算检查清单

建议按这个顺序验证你的推导和计算。

## B.1 内参矩阵的逆

把 K 和 K^(-1) 乘起来，逐项检查是否等于单位矩阵。
**重点检查 (1,3) 位置**，那里最容易出错：

```
   α · (γ·v0 - β·u0)/(α·β)  +  γ · (-v0/β)  +  u0 · 1

     =  (γ·v0 - β·u0)/β  -  γ·v0/β  +  u0

     =  (γ·v0 - β·u0 - γ·v0)/β  +  u0

     =  -u0  +  u0

     =  0                                          对上了
```

## B.2 B 的对称性

检查 B12 = B21，B13 = B31，B23 = B32。
在你手算出的 B 矩阵里，这三个等式应该成立。

## B.3 组合量 (2) 的抵消

第 7.2 节的组合量 (2) 推导里，四项两两抵消：

```
   -γ²·v0  +  γ·β·u0  -  γ·β·u0  +  γ²·v0  +  α²·v0
   [-----]    [---------------------]    [-------]
   抵消               抵消                 剩下
```

**这是整个推导里最关键的一步**，建议亲手验一遍。

## B.4 λ = 1 的验证

对理论值 B，第 7.4 节应该算出 λ = 1。
这可以作为"你的 B 表达式是否正确"的自检。

如果算出来不是 1，说明第 5.5 节某个 B 元素写错了。

## B.5 尺度不变性

把 B 整体乘以 2，然后重新跑第 7 章的六个公式，
**结果应该完全不变**。这是验证公式正确性的最强手段。

## B.6 外参的正交性

算出 r1, r2, r3 后检查：

```
   r1 与 r2 的内积  ≈  0

   r1 与 r3 的内积  ≈  0

   r2 与 r3 的内积  ≈  0

   ‖r1‖  ≈  1

   ‖r2‖  ≈  1

   ‖r3‖  ≈  1
```

**不用做到完全精确**（因为有噪声），但应该很接近。
如果差得远，说明 K 算错了。

## B.7 单应的重建

用求出的 H 把板上的点 (X, Y) 投影回像素，
和实际检测的像素比较。对 4 个用于求解的点来说，误差应该接近 0
（因为 4 个点 8 个方程正好解 8 个未知数，是恰定的）。

对**没有参与求解**的点，误差才反映真实精度。

## B.8 常见错误速查

| 症状 | 可能原因 |
|---|---|
| v0 算出来是天文数字 | B11·B22 - B12² 接近 0，说明 B 算错了或数据退化 |
| α 是负数或虚数 | λ / B11 为负，说明 B 不正定（数据或者符号错了） |
| λ 算出来不是正数 | B33 或组合量 (3) 有符号错误 |
| 外参正交性差很多 | K 有误差，或者 h1, h2, h3 的取法错了 |
| u0 飞出图像范围 | 数据覆盖不足，或第 7.8 节的 γ·v0/β 项漏掉了 |

# 附录 C　推荐的手算小例子设计

如果你想手算一遍，建议这样设计一个最小可算的例子：

**第 1 步**：自己设定内参真值

```
   α = 1000,  β = 1000,  γ = 0,  u0 = 640,  v0 = 480
```

（γ 取 0 可以大幅简化手算。）

**第 2 步**：用一个简单的旋转

```
   让标定板绕 y 轴转 30 度，平移 t = (0, 0, 500)
```

则 R 的三个列是：

```
   r1 = ( cos30,  0,  -sin30 ) = ( 0.8660,  0,  -0.5000 )

   r2 = ( 0,  1,  0 )

   r3 = ( sin30,  0,   cos30 ) = ( 0.5000,  0,   0.8660 )
```

**第 3 步**：直接算 H（不用真的做角点检测）

```
   H  =  K · [ r1  r2  t ]
```

把 K 和 [r1 r2 t] 乘起来。这一步能帮你熟悉 H 的结构。

**第 4 步**：验证 h1 和 h2 满足约束

用这个 H 算出 B11 到 B33（用第 5.5 节，虽然你还是用真值 K），
然后验证：

```
   h1 的转置 · B · h2  =  0        （应该精确成立）
```

**第 5 步**：做两张不同角度的图

用两个不同的 R，得到 H1 和 H2，
构造 V（4 行 6 列），加上 γ = 0 的约束（第 5 行），
对 V 做 SVD 求 b，再由 b 反解出 K，
看是否还原出 α = 1000, β = 1000, u0 = 640, v0 = 480。

**这一步做完，你就完整走通了张氏标定法。**
